# xhs-clone · 小红书风格社区网页程序（UI Demo）

单文件 HTML5 社区内容 App，**UI/交互高度复刻小红书核心界面**（标志红 `#ff2442` + 白底），零 CDN、零构建、零外链图片（封面为 **SVG 生成的渐变插画占位**，头像为**首字母色块**，均为原创占位素材，不含小红书版权 Logo/内容）。

## 核心功能

### 🏠 首页（信息流）
- 顶部品牌栏 + 搜索框（**实时过滤**标题/作者/正文）
- **10 个频道 tab**（推荐/关注/穿搭/美食/旅行/家居/健身/美妆/读书/数码/宠物）横向滑动切换
- **双列瀑布流卡片**（封面插画 + 两行标题 + 头像昵称 + 点赞数，卡片点赞可直接点）
- "关注"频道只显示已关注作者/自己的笔记

### 📄 笔记详情页
- 顶部返回 + 作者头像昵称 + **关注按钮**（切换状态）
- **3 图轮播**（左右箭头 + 圆点指示 + 平滑过渡）
- 标题 / 正文 / 话题标签（点击跳搜索）/ 发布时间
- **点赞 ❤️ / 收藏 ⭐ / 评论数 / 分享**（状态实时生效）
- **评论列表 + 输入框发评论**（回车或按钮发布，插入列表）

### ✍️ 发布页
- 标题（40 字）+ 正文（1000 字）+ 话题选择 + 封面配色选择
- 校验标题非空 → 入库并置顶"我"的笔记 + 首页可见

### 💬 消息页
- 赞和收藏 / 新增关注 / 评论回复 / 系统通知 / 薯队长（带红点角标）

### 👤 "我"主页
- 头像 + 昵称 + 小红薯号 + 简介
- **关注 / 粉丝 / 获赞收藏** 统计（粉丝随关注数动态变化）
- **3 tab：笔记 / 收藏 / 赞过**（各自网格，空态提示）
- 发布 / 编辑资料 / 设置入口

### 🔁 持久化（localStorage `xhs_clone_v1`）
点赞、收藏、关注、自发布笔记、发表评论 —— 刷新不丢。

## 导航

- 底部 **5 tab**：首页 / 消息 / ＋发布 / 我 / 购物（演示）
- 详情页顶部返回 ←、发布页 ✕ 取消
- toast 轻提示反馈

## 视觉

- 小红书标志性红 `#ff2442` 渐变点缀、白底浅灰内容区
- 卡片圆角阴影、频道胶囊高亮、关注按钮红底、评论吸底输入框
- 手机上满屏 App 感，桌面居中**手机壳容器**（圆角边框 + 阴影）

## 响应式（三档断点）

- ≤640px：去手机壳、满屏、卡片标题微缩
- ≤420px：品牌文字隐藏、卡片间距/圆角收紧、头像与统计压缩

## 本地运行

```bash
open index.html                 # 浏览器直接打开
# 或
python3 -m http.server 8080    # http://localhost:8080
```

## 结构（单文件 index.html）

- 样式：CSS 变量品牌配色、顶栏/频道/瀑布流/详情/发布/消息/我的/底部 tab、三档媒体查询
- 数据：`SEED` 12 篇种子笔记、`PALETTES/coverSVG/avatarHTML` 生成占位素材
- 状态：`store`（likes/favs/follows/cmts/mine）+ `save/load` localStorage
- 视图：`showView/switchTab` 路由、`renderFeed/renderDetail/renderPublishOptions/renderMessages/renderMe`
- 交互：`toggleLike/toggleFav/toggleFollow/slide/sendCmt/doPublish/onSearch/setChan`

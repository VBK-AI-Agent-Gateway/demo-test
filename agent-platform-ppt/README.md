# agent-platform-ppt · 个人智能体助手平台业务介绍 PPT

单文件 HTML5 **网页版演示文稿**（幻灯片），深色科技风，介绍"个人智能体助手平台（AgentHub）"业务，共 13 页。零 CDN、零 reveal.js、零构建。

## 页面清单（13 页）

1. 封面 — 标题 + 汇报信息 + 操作提示
2. 目录 — 自动生成 10 章节导航（可点击跳转）
3. 市场与痛点 — 4 卡（工具割裂/无记忆/不会动手/成本不透明）
4. 产品定位 — 三层价值 + 产品愿景引用
5. 核心能力 — 六大引擎（多 Agent 编排/工具 MCP/知识库/工作流/记忆/安全）
6. 平台架构 — 四层解耦架构图（接入/智能体/能力/基座，CSS 手绘）
7. 典型场景 — 4 高频用例（晨间情报/内容创作/开发副驾/事务管家）
8. 差异化优势 — 与通用聊天 AI、单点工具的对比表
9. 商业模式 — 免费/专业/团队三档定价 + 收入结构
10. 发展路线图 — 四阶段时间轴 + 3 个 KPI 目标
11. 关键指标 — 8 个 Traction 数据卡
12. 团队与生态 — 核心团队/生态合作/护城河 + 信念引用
13. 结尾 CTA — 大标题 + 预约演示/商务合作按钮 + 二维码占位

## 导航

- **键盘**：`→` / `空格` / `PageDown` 下一页；`←` / `PageUp` 上一页；`Home`/`End` 首/末页；`T` 缩略图网格；`F` 全屏；`Esc` 关闭缩略图
- **点击**：屏幕右侧 28% 区域下一页、左侧 18% 上一页；底部 `‹ ›` 按钮；`▦` 打开缩略图；`⛶` 全屏
- **触摸**：左右滑动翻页（手机可用）
- **滚轮**：上下滚动翻页（500ms 节流）
- **进度**：底部渐变进度条 + `页码 / 总数`

## 视觉

深色网格底纹、渐变高光标题、发光卡片顶条、浮动光球（封面）、四层架构图、定价高亮卡、路线时间轴、对比表斑马纹。

## 响应式（三档断点）

- ≤900px：目录单列、路线图竖排、光球隐藏
- ≤640px：卡片网格单列、slide 纵向滚动
- ≤420px：封面 meta、目录序号、按钮进一步压缩

## 本地运行

```bash
open index.html                # 浏览器直接打开
# 或
python3 -m http.server 8080   # http://localhost:8080
```

## 结构（单文件 index.html）

- 样式：CSS 变量科技配色、slide 绝对定位 + transform 过渡、卡片/表格/架构/路线组件、三档媒体查询
- 内容：`<section class="slide" data-t data-d>` 每页一段业务文案
- 引擎：`go/next/prev/updateHud` 切换与 HUD、`buildThumbs/openThumbs` 缩略图、TOC 自动生成
- 交互：键盘/按钮/点击区域/触摸 swipe/滚轮，全屏 API

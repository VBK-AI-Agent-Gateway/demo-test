03 · CAPABILITIES

🤖

写作、研究、编程、日程等多 Agent 并行/串行协作，主管 Agent 自动拆解任务分发。

🛠️

工具 & MCP 调用

内置 100+ 工具，兼容 MCP 协议，一键接入浏览器、文件、日历、数据库与第三方 API。

📚

个人知识库

笔记/文档/网页自动向量化，RAG 检索带引用回答，越用越懂你。

⚙️

工作流自动化

可视化编排定时代理：早报、竞品监控、周报生成、社媒分发全自动。

🧬

长期记忆

用户画像 + 事件记忆双通道，跨会话保持偏好、项目与语气一致性。

🔐

安全与隐私

本地优先存储、端到端加密、细粒度权限与审计日志，敏感数据可脱敏。

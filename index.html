prisma-task-api

Express + Prisma + PostgreSQL 的 Project / Task CRUD API：zod 输入校验、统一错误信封、分页、搜索、Prisma 迁移与种子数据、Supertest 集成测试、docker compose 一键启动。

验证: zod 错误: 统一信封 分页 + 搜索 迁移 + 种子 Supertest 集成测试 docker compose up

快速启动

# 启动 PostgreSQL + 迁移 + 种子 + API（端口 3000）
docker compose up --build

# 跑 Supertest 集成测试（容器内起 Postgres 并执行 Jest）
docker compose -f docker-compose.test.yml up --abort-on-container-exit --exit-code-from api

# 本地开发
cp .env.example .env
npm install
npx prisma migrate deploy
npm run seed
npm run dev

API 端点

Projects

方法路径说明
GET/api/projects列表 · query: page pageSize(≤100) q
GET/api/projects/:id详情（含 tasks）
POST/api/projects创建 {name, description?}
PUT/api/projects/:id部分更新
DELETE/api/projects/:id删除（级联删任务）

Tasks

方法路径说明
GET/api/tasks列表 · query: page pageSize q status priority projectId
GET/api/tasks/:id详情（含 project）
POST/api/tasks创建 {title, projectId, status?, priority?, dueDate?, description?}
PUT/api/tasks/:id部分更新
DELETE/api/tasks/:id删除

GET /health 健康检查 · GET /api 端点索引

响应与错误信封

列表响应
{
  "data": [...],
  "pagination": {
    "page": 1,
    "pageSize": 10,
    "total": 25,
    "totalPages": 3
  }
}
统一错误
{
  "error": {
    "code": "BAD_REQUEST",
    "message": "Validation failed",
    "details": { "fieldErrors": {} }
  }
}

400 BAD_REQUEST · 404 NOT_FOUND · 422 VALIDATION_ERROR · 500 INTERNAL_ERROR

curl 示例

# 创建项目
curl -X POST http://localhost:3000/api/projects \
  -H 'content-type: application/json' \
  -d '{"name":"Demo","description":"A demo project"}'

# 分页 + 搜索
curl 'http://localhost:3000/api/projects?page=1&pageSize=5&q=demo'

# 创建任务
curl -X POST http://localhost:3000/api/tasks \
  -H 'content-type: application/json' \
  -d '{"title":"Write docs","projectId":"<PROJECT_UUID>","priority":"HIGH"}'

# 更新任务状态
curl -X PUT http://localhost:3000/api/tasks/<TASK_UUID> \
  -H 'content-type: application/json' \
  -d '{"status":"DONE"}'

# 删除
curl -X DELETE http://localhost:3000/api/tasks/<TASK_UUID>

集成测试覆盖（Supertest）

创建项目/任务 201；缺 name/title、空字符串、非法枚举、未知 projectId → 400 信封
查询按 id 返回详情含关联；未知 id → 404 信封；非法 uuid → 400
更新PUT 部分更新生效；未知 id → 404
删除DELETE → 204，随后 GET → 404
分页25 条数据 page1/2/3 切片正确、total/totalPages、page=0 与 pageSize>100 → 400、相邻页无重叠
搜索q 大小写不敏感、命中总数正确、无结果返回空列表；status/projectId 过滤

目录结构

src/
  app.js                # express app 工厂（测试可直接挂载）
  server.js             # 启动入口（内置零依赖 .env 读取）
  lib/prisma.js         # Prisma 单例
  middleware/validate.js# zod 校验中间件（body/query/params）
  middleware/error.js   # ApiError + 404 + 统一错误处理 + Prisma 错误映射
  routes/projects.js    # Project CRUD + 分页 + 搜索
  routes/tasks.js       # Task CRUD + 分页 + 搜索 + 过滤
prisma/
  schema.prisma         # Project / Task + 枚举 + 索引
  seed.js               # 3 项目 / 12 任务种子
  migrations/           # prisma migrate 生成的迁移
tests/api.test.js       # Supertest 集成测试
docker-compose.yml      # db + api（healthcheck 后 migrate deploy + seed）
docker-compose.test.yml # db + jest
Dockerfile  README.md  jest.config.js  package.json
